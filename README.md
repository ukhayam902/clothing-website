# Clothing Website

A clean white/black clothing e-commerce storefront for shirts and tees.

- Placeholder store name on the site: UK Threads (not confirmed as the final brand name)
- 30 products: 13 shirts, 13 tees, 3 polos, 1 oversized tee
- Product detail with sizes S-XXL, Add to Cart / Buy Now, cart drawer, Cash-on-Delivery checkout
- All product photos are labelled representative and all prices are labelled samples, to be confirmed by the shop owner.

## Run

Open `index.html` — it is a single self-contained static page (all assets inlined).

## SEO

- Canonical + Open Graph/Twitter meta and JSON-LD (WebSite, Organization, FAQPage) in `index.html`.
- `robots.txt`, `sitemap.xml`, `llms.txt`, `llms-full.txt` at the site root.
- Google Search Console verification file `google38067bd907e81902.html` at the site root.
- Brand name 'UK Threads' is a placeholder (not confirmed); all photos are representative and all prices are samples.
